# 沉浸式专注阅读模式 (Zen Mode)

现代工程技术专栏、架构白皮书与长篇教程通常需要读者高度聚焦于长段落与代码推演。然而，屏幕两侧充斥的目录树、大纲导航以及顶部工具栏常会带来无形的视觉噪点。

**VitePress Zenith** 独家研发了**分层解耦的专注阅读模式（Zen Mode）**与**流光阅读进度指示器**。

---

## 核心特性与体验

### 1. 快捷键与一键切换

- **快捷键**：按下 <kbd>Alt</kbd> + <kbd>Z</kbd>（macOS 用户按 <kbd>⌥ Option</kbd> + <kbd>Z</kbd>）随时切换模式；
- **悬浮悬钮**：页面右下角常驻半透明悬浮控制按钮，点击即可快速折叠或展开全局面板；
- **本地记忆**：读者的专注阅读偏好会自动持久化存储于浏览器的 `localStorage` 中。

### 2. 双向硬件加速展翼动效

与简单的宽度拉伸不同，Zenith 采用了**分层解耦过渡架构**：
- **左右对称滑移**：左侧目录栏向左、右侧大纲向右平滑退场；
- **内容呼吸居中**：正文容器平滑过渡至 `1180px` 黄金沉浸阅读宽度；
- **顶栏宽度隔离**：顶栏网格保持稳定定位，彻底根除搜索框与导航菜单横向位移引起的抽搐跳跃。

---

## 顶部阅读进度条

在长文滚动过程中，页面顶端呈现极细的品牌渐变进度指示条：
- 实时计算视口已阅读百分比；
- 滚动至页面最顶端时自动隐藏；
- 硬件加速 `transform: scaleX(...)` 驱动，60fps 丝滑不引起重排。

---

## 状态钩子 API (useZenMode)

如果您需要在自定义组件或业务逻辑中读取或控制专注模式，可以直接引入响应式状态钩子：

```ts
import { useZenMode } from '../composables/useZenMode'

const { isZenMode, toggleZenMode, exitZenMode } = useZenMode()
```
