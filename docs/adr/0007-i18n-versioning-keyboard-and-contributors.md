# 引入多语言国际化矩阵、多版本演进、全键盘导航与开源贡献者致谢体系

为了使 VitePress Zenith 模板全面适应大型国际化开源项目、长生命周期技术软件维护以及极客开发者的深度协同，我们决定构建第四阶段全球化与开源生态协同体系。

## 考虑备选

- **多语言国际化 (i18n)**：
  - 纯单语言锁定：局限于纯中文技术团队，阻碍开源项目走向国际舞台；
  - 双语标准化骨架：基于 VitePress 原生 locales 体系，根路径保持中文极致体验，提供 `/en/` 对应映射骨架，顶栏无缝激活语言切换，自动侧边栏与离线检索分词各自独立运作。
- **多版本生命周期管理**：
  - 单版本粗暴覆写：技术库发布新大版本（如 2.0）时，直接破坏使用旧版（1.x）开发者的文档链接与查阅诉求；
  - 版本下拉切换与归档警告横幅：顶栏提供语义化版本选择，进入被标记为历史版本的文档时，自动在页面顶部注入醒目警示横幅与新版跳转按钮。
- **全键盘极客导航 (<kbd>?</kbd> Cheat Sheet)**：
  - 传统重度依赖鼠标：阅读文档与翻页频繁需要抓取鼠标移至屏幕底端；
  - 全键盘支持：全局监听 <kbd>?</kbd> 呼出快捷键速查表；提供 <kbd>J</kbd>/<kbd>K</kbd> 极客翻页、<kbd>T</kbd> 切换主题与 <kbd>Alt+Z</kbd> 专注模式。
- **开源贡献者激励与致谢**：
  - 仅展示无感知的最后更新时间：无法建立对参与文档建设的社区开发者的正向激励；
  - Git 贡献者头像流与编辑指引：自动拉取单文件 Git Commit 提交者头像列表并展示于文档底部，提供直达 GitHub 的一键编辑入口。

## 产生的后果

- Zenith 具备从“个人技术知识库”到“世界级开源大厂技术基础设施”的全面进化能力；
- 读者享受到媲美原生 IDE 的纯键盘流阅读与无障碍探索；
- 社区协作门槛显著降低，开源技术文章的权威性与温度感倍增。
