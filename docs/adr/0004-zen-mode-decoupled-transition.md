# 采用硬件加速对称滑出与分层解耦的专注模式转场动效

为了彻底消除专注模式切换时因暴力应用 `transition: all` 引发的正文文字逐行抖动（Reflow Thrashing）与顶部导航栏元素横向撕裂抽搐，我们决定采用分层解耦的硬件加速转场策略。

## 考虑备选

- 全局应用 `transition: all 0.3s`：实现最简单，但强行补间 `max-width` 与 `position` 会引发严重的回流震颤与文字跳跃。
- 零延迟瞬时切换（Instant Switch）：完全无回流开销，但缺乏现代顶配文档系统的交互呼吸感与沉浸仪式感。
- View Transitions API 快照过渡：视觉效果好，但对低版本浏览器兼容性不足，且无法与复杂的侧边栏滑动物理协同。

## 产生的后果

- 左侧边栏（`translateX(-100%)`）与右侧大纲（`translateX(100%)`）实现左右对称的 GPU 硬件加速滑出，帧率维持在 60fps。
- 顶部导航栏（Navbar）元素解除位移补间，保持结构稳定瞬变，彻底根除搜索框与标题横向位移抽搐。
- 正文容器平稳舒展，杜绝 300ms 内每秒 60 帧连续触发表段文字断点重排（Line-wrap Jitter）。
