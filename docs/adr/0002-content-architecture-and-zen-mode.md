# 架构与体验决策：集中式内容目录、沉浸式阅读与原生能力扩展

为了提供极致的文档查阅与编写体验，我们决定采用集中式 `docs/` 目录组织，全面启用原生 Local Search、MathJax 数学公式与 UnoCSS 图标体系，并通过主题插槽定制支持一键折叠左右侧栏的“沉浸式阅读模式 (Zen Mode)”。

## 考虑备选

- 采用 Pagefind 离线检索：检索能力强，但在本地开发热更新阶段体验不如官方内置 Minisearch 丝滑。
- 原生左中右固定布局：在大屏或深度长文阅读场景下左右栏信息密度过大，分散读者注意力。

## 产生的后果

- 项目根目录职责清晰，所有内容、样式扩展与资源内聚在 `docs/`。
- 读者可随时通过顶部/悬浮操作栏或快捷键（`Alt+Z`）切换至单列沉浸式正文聚焦模式。
- Markdown 中支持原生 `$...$` 与 `$$...$$` 数学公式，以及 `i-lucide-*` 纯 CSS 图标。
