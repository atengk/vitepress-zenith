# 引入内链悬浮预览、PWA离线可用、结构化API契约与在线沙箱直达

为了将 VitePress Zenith 打造成具备全球顶尖水准（对标 Supabase、Stripe Docs、Mintlify、Notion）的技术知识库与工程文档引擎，我们决定启动第三阶段技术扩展：深度解决内链跳转打断心流、弱网与移动离线不可用、复杂参数表格排版拥挤以及代码片段不可独立试玩等核心痛点。

## 考虑备选

- **内链信息求证体验**：
  - 传统方案：读者点击内链跳出当前页面，查阅后再依靠“后退”按钮返回，极易打断深度阅读心流；
  - 悬浮卡片预览 (Link Hover Preview)：光标悬停站内文档链接 300ms 自动弹出包含标题、标签与摘要的微型悬浮卡片，移出即隐退，零跳转完成背景确认。
- **离线与断网查阅体验**：
  - 普通纯在线网页：网络中断或弱网环境下直接白屏无法访问；
  - PWA 渐进式应用：通过 Service Worker 预缓存静态资产与文档 HTML，断网时秒级极速打开，且支持将知识库“安装”为无浏览器边框的独立桌面/移动原生窗口。
- **API 参数与配置清单呈现**：
  - 原生 Markdown 表格：在移动端或窄屏侧边栏展开时容易出现宽表格截断，且缺乏代码类型高亮与“必填”语义；
  - `<VpApiTable>` 专用契约组件：桌面端呈现自适应网格，移动端无缝降级为卡片折叠流，原生内置类型胶囊与默认值标签。
- **代码示例验证与实战调试**：
  - 仅文档静态展示：读者修改测试需手动在本地新建项目；
  - 一键投送 StackBlitz 在线沙箱：点击直接将演示代码打包送入浏览器虚拟机，零成本即时试跑与调试。

## 产生的后果

- 知识网络连通性与阅读沉浸度实现质的突破，读者在长篇技术白皮书中畅行无阻；
- 移动端与离线环境查阅体验达到 Native App 级水准；
- API 文档专业度与移动端可读性大幅提升；
- 交互演示沙箱具备从“静态看”到“在线玩”的完整闭环。
