# 开发者体验与旗舰扩展：Twoslash、Markmap、联动选项卡与运营套件

为了让模板达到业内顶级技术文档工程标准，我们决定集成 Shiki Twoslash 类型悬浮系统、Markmap 思维导图、全站同步的包管理器选项卡、全局阅读进度条与生产级运营套件（公告横幅、文档反馈、SEO/Sitemap）。

## 考虑备选

- 采用传统静态代码块：缺乏动态类型悬浮能力，读者无法直接在网页中探查复杂 API 返回值与泛型定义。
- 仅提供孤立的手工代码 Tabs：读者在每篇文档中都需要重新点击切换至自己常用的包管理器（如 pnpm），造成重复操作疲劳。

## 产生的后果

- TypeScript 代码块支持完整的 VS Code 级类型提示（`// ^?`）与错误波浪线展示。
- 读者只需选择一次偏好的包管理器，全站所有页面自动同步并记忆。
- 提供 Markmap 思维导图与 Mermaid 流程图双引擎，满足不同维度的可视化诉求。
- 内置顶部公告通知条与“本文对您有帮助吗”反馈闭环，满足生产级运营与质量迭代需求。
