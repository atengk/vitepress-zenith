# 深度沉浸：VitePress Zenith 专注模式的架构与动效设计

在现代技术文档与长篇工程专栏的阅读过程中，屏幕两侧的侧边栏、右侧大纲导航以及顶部浮动工具栏虽然提供了便捷的定位能力，但在需要高专注度推演代码与阅读长文时，往往会形成显著的视觉干扰。

为了给读者提供纸质读物般的沉浸式体验，**VitePress Zenith** 打造了全功能的专注阅读模式（Zen Mode）。

## 架构演进与挑战

早期专注模式尝试直接对正文容器实施宽度缩放，但在实际应用中引发了三大痛点：

1. **文字回流与重排抖动**：正文容器宽度变化触发长段落反复重新折行，视觉体验生硬；
2. **顶栏导航横向抽搐**：全宽顶栏在响应折叠过渡时，搜索框与导航链接因网格重新计算产生位置跳跃；
3. **滚动锚点偏移**：在长文阅读过程中切换模式，视口中心容易脱离正在阅读的段落。

## 分层解耦设计方案

通过将专注模式状态完全交由 `useZenMode` 状态机接管，配合全站统一的 CSS 变量驱动，实现了零抖动的双轴展翼过渡：

```ts twoslash
interface ZenModeState {
  isActive: boolean
  toggle: () => void
  exit: () => void
}
```

正文宽度保持渐进式平滑过渡，侧边栏与大纲栏采用独立图层的 `opacity` 与 `transform` 左右对称滑移，使视线始终牢固锁定在核心阅读区域。
